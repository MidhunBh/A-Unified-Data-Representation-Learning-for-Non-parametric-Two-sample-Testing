# Diagnostics

This directory contains diagnostic and exploratory experiments used to
understand reproduction discrepancies, implementation choices, and
representation behaviour.

The diagnostic results are intentionally retained, including negative or
superseded experiments, when they document how a validated configuration
was obtained.

## Structure

- `c2st/` — C2ST/RL-C2ST implementation and representation diagnostics.
- `hdgm/` — HDGM-specific checks and reproduction diagnostics.
- `mnist/` — MNIST-specific checks.
- `representation/` — representation-level analyses.
- `tabpfn/` — TabPFN representation diagnostics.

Files in this directory are research provenance rather than the primary
reproduction entry points.
